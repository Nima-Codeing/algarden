# 0005. 着火点は「葉からの高さ」で重みを付けて選ぶ

- 状態：採用
- 決定日：2026-06-30

## 背景

新しいノードをどのノードに生やすか（着火点）の選び方で、庭の形が決まる。毛玉とハブは延焼（[0004](0004-forest-fire.md)）が作るので、着火点の役目は、木をかたよりなく広げることだけになった。

## 検討した案

### 子の数で重みを付ける（子が多いほど選ばれやすい）

- 中心のノードばかりが選ばれ、そこだけが肉団子のように膨らむ。

### ルートからの深さで重みを付ける（深いほど選ばれやすい）

- 一番深いノードばかりが選ばれ、一本道に伸びていく。

## 決定

子が4未満のノードを候補にし、次のどちらかで1つ選ぶ。

- 確率 `P_LEAF` で、葉に近いノードほど選ばれやすい抽選をする。高さは葉を0とし、親の高さは「子の高さの最大 + 1」とする。
- 残りの確率で、候補から完全にランダムに選ぶ。伸びていない枝にも芽を出させるためである。

## 結果

- 【当初】：決めたときに見込んでいたこと
- 【年-月】：後から分かったこと（分かった時期）

### メリット

- 【当初】葉はすべての枝にあるので、葉を優先しても1本の枝だけが伸び続けることはない。内側のノードは選ばれにくいので、肉団子にもならない。

### デメリット

- 【当初】葉を優先しすぎると、どのノードも子を1つずつしか持たない、細い鎖のような形になる。`P_LEAF` と重みの付け方で調整する。

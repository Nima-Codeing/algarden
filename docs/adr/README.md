# ADR（設計判断の記録）

AlGarden で行った設計上の判断を、1つの判断につき1ファイルで残す。何を選んだかだけでなく、比べた案と、選ばなかった理由も書く。

もともとは Notion の判断ログに残していたが、コードを読む人が「なぜこの設計なのか」をリポジトリの中で追えるように、ここへ移した。

## 書き方

Michael Nygard の ADR の形に、「検討した案」を足している。

| 見出し | 書くこと |
| --- | --- |
| 背景 | 決めた当時の状況と、困っていたこと |
| 検討した案 | 比べた案と、選ばなかった理由 |
| 決定 | 何を選んだか |
| 結果 | 良くなったことと、引き受けた欠点 |

状態は「採用」か「置き換え済み（→ 新しい ADR の番号）」のどちらか。判断が変わったときは、古い ADR を消さずに状態だけを書き換え、新しい ADR を足す。
